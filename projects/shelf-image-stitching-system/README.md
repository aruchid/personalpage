# 图像全景拼接算法系统

## 项目简介

图像全景拼接算法系统是一个基于计算机视觉技术的智能图像拼接解决方案，专为货架商品识别场景设计。该系统实现了多视角图像的无缝拼接和自动化SKU统计，显著提升了零售行业的工作效率。

## 项目特点

- **技术创新**：重新设计图像配准、特征匹配和几何变换等关键算法模块
- **场景优化**：针对货架近距离拍摄场景的特殊性进行算法优化
- **性能提升**：处理速度提升3倍，显著降低计算资源消耗
- **移动端适配**：成功移植到移动设备，实现实时全景拼接
- **商业价值**：实现商品数量自动化统计，显著提高工作效率

## 核心技术

### 算法流程
1. **特征点检测**：使用SURF/SIFT算法检测关键特征点
2. **特征匹配**：通过KNN搜索和RANSAC算法进行特征点匹配
3. **几何变换**：计算单应性矩阵，实现透视变换
4. **图像配准**：应用投影变换将图像对齐到同一坐标系
5. **图像融合**：使用最大流图割法确定拼接线，应用Pyramid融合技术
6. **全景输出**：生成高质量的全景图像

### 技术特点
- SURF/SIFT特征提取
- RANSAC错误剔除
- 单应性矩阵计算
- Pyramid融合技术
- 最大流图割法
- 色彩校正与融合

## 使用方法

直接在浏览器中打开 `index.html` 文件，查看完整的项目介绍和技术细节。

### 2. 生成主图
运行Python脚本生成系统架构图：

```bash

# 运行脚本
```
