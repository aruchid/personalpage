This project designs a multi-brushless motor drive control system based on FreeRTOS real-time operating system, capable of simultaneously driving three brushless motors with concurrent control capabilities. The system employs a hybrid control strategy, integrating traditional six-step commutation control and advanced FOC (Field Oriented Control) technology to provide optimal control solutions for different motor application scenarios. The hardware architecture utilizes STM32F4 series microcontrollers, complemented by three-phase bridge power drive circuits, Hall sensors, encoders, and other sensor modules, along with CAN bus and RS485 communication interfaces. The software architecture is built on FreeRTOS multi-threading design, implementing core tasks including motor control, communication processing, system monitoring, and human-machine interaction, ensuring 1ms control cycle and ±0.1% speed control accuracy. The system features comprehensive protection functions including overcurrent, overvoltage, and overtemperature protection, as well as fault diagnosis and alarm mechanisms. Through modular design and standardized interfaces, the system offers excellent scalability and maintainability, suitable for industrial automation, robotics control, and other applications requiring high-precision multi-motor synchronization control.
