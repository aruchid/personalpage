# 数据字典

## 玩家基础信息（玩家基础信息.csv）
- user_id：玩家唯一标识
- register_time：注册时间
- last_login_time：最后登录时间
- level：玩家等级
- gender：性别
- age：年龄
- device_type：设备类型
- region：地区

## 玩家充值记录（玩家充值记录.csv）
- user_id：玩家唯一标识
- pay_time：充值时间
- pay_amount：充值金额
- pay_type：充值方式

## 玩家每天在线时长（玩家每天在线时长.csv）
- user_id：玩家唯一标识
- date：日期
- online_minutes：当天在线时长（分钟）
