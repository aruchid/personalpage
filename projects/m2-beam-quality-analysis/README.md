# M²激光测量系统

## 项目概述

本项目开发了一套基于ISO 11146标准的M²激光测量系统，用于精确测量激光束质量因子。系统通过多平面采样和光束传播拟合，实现激光束参数的自动化、高精度测量。

## 技术原理

### M²因子定义
M²因子是衡量激光束质量的核心参数，定义为：
```
M² = (w₀θ)实际 / (w₀θ)理想
```
其中：
- w₀：束腰半径
- θ：发散角
- M² = 1表示理想高斯光束

### 测量方法
基于激光束传播方程：
```
w²(z) = w₀² + (M²λ/πw₀)²(z-z₀)²
```
通过测量多个z位置的光束宽度w(z)，拟合得到M²因子等参数。

## 系统架构

### 核心组件
1. **激光源**：支持400nm-2000nm波长范围
2. **聚焦透镜**：高精度双凸透镜
3. **分束器**：激光束分束和参考光路
4. **CCD探测器**：高灵敏度图像传感器
5. **平移台**：精密机械控制，实现多平面采样

### 测量流程
1. 激光束通过聚焦透镜
2. 在焦点前后多个位置测量光束宽度
3. CCD采集各位置的光强分布
4. 计算光束宽度并拟合传播方程
5. 输出M²因子、束腰半径、发散角等参数
