# RK3588算法快速部署平台

## 项目概述

本项目是一个基于嵌入式的算法通用平台，旨在将包括目标检测、计数、检测范围框自适应、分类、缺陷检测等算法部署在RK系列嵌入式平台上以及Jetson平台上。通过低成本化工控的方式降低了智能相机的使用门槛，为工业应用提供了经济高效的解决方案。

## 技术架构

### 核心平台支持
- **RK系列嵌入式平台**：针对瑞芯微RK3588等高性能ARM芯片优化
- **NVIDIA Jetson平台**：支持Jetson Nano、Xavier NX等边缘计算设备
- **多算法类型支持**：目标检测、计数、分类、缺陷检测、区域定位等

### 技术特点
- **算法优化**：针对嵌入式设备的硬件限制进行算法重新设计和优化
- **软硬件协同**：整体软硬件架构设计，算法与硬件深度集成
- **低成本方案**：通过工控方式降低智能相机使用门槛
- **跨平台兼容**：支持多种嵌入式平台，实现算法的高效移植

# Abstract

This project presents an RK3588-based embedded algorithm deployment platform that enables rapid deployment of computer vision algorithms including object detection, counting, classification, and defect detection on RK series embedded platforms and NVIDIA Jetson devices. The platform addresses the challenge of deploying complex image processing algorithms on resource-constrained embedded systems through hardware-specific optimization and software-hardware co-design. Key features include cross-platform compatibility, real-time inference optimization, and cost-effective industrial solutions that lower the barrier to intelligent camera adoption. The platform successfully demonstrates algorithm transplantation capabilities while maintaining system stability and performance, providing reliable technical support for industrial inspection, smart manufacturing, and edge AI computing applications.
