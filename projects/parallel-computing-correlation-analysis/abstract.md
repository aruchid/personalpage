# Abstract

This project develops a high-performance stock correlation analysis system based on parallel computing technology, integrating multiple advanced correlation calculation methods including Granger causality testing, information entropy analysis, mutual information computation, F-test statistics, GCS scoring, conditional mutual information, transfer entropy, and information gain. The system employs a multi-threaded CPU parallel computing architecture with GPU acceleration support through CuPy library for large-scale matrix operations, significantly improving computational efficiency. In data processing, the system supports CSV and NPY format data reading with automatic data preprocessing and cleaning capabilities, efficiently handling large-scale financial time series data. The modular design includes data preprocessing, parallel computing, GPU acceleration, result analysis, and visualization modules, achieving 15x acceleration in matrix operations through GPU optimization. The system provides comprehensive financial data mining capabilities for stock correlation analysis, portfolio optimization, and risk management strategy development, offering reliable technical support for quantitative investment decision-making while advancing parallel computing technology in the financial technology domain.
